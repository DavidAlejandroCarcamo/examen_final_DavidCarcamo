## Descripción del proyecto

Este proyecto consiste en el desarrollo de módulos personalizados para Odoo 20.0, con el objetivo de mejorar procesos administrativos y comerciales de la Universidad Católica de Honduras.

Se desarrollaron dos módulos utilizando Python, XML y CSV.

## 1. Módulo Tienda UNICAH

**Carpeta:** `tienda_unicah`

Permite administrar clientes universitarios y aplicar convenios de descuento en la tienda de UNICAH.

### Funcionalidades

- Registro de estudiantes, docentes, administrativos y clientes externos.
- Número de cuenta y carrera para estudiantes.
- Creación y administración de convenios.
- Aplicación de descuentos en cotizaciones.
- Validación de números de cuenta.
- Validación de porcentajes y fechas de convenios.
- Límite de 10 unidades por pedido para estudiantes.
- Cálculo del ahorro por convenio.
- Filtros y agrupaciones de cotizaciones.

## 2. Módulo Préstamos UNICAH - Ejercicio 6

**Carpeta:** `unicah_prestamos_ejer6`

Módulo diseñado para administrar los préstamos de equipos universitarios a estudiantes y docentes.

### Funcionalidades

- Registro de préstamos de equipos.
- Asociación de préstamos con contactos de Odoo.
- Registro de fechas de préstamo y devolución.
- Estados: solicitado, prestado y devuelto.
- Cálculo automático de días de préstamo.
- Validación de fechas incorrectas.
- Vistas de lista y formulario.
- Menú propio de Préstamos UNICAH.
